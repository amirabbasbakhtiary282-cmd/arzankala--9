# به‌روزرسانی ورک‌فلو تست خودکار (CI)

ورک‌فلو فعلی `.github/workflows/backend-health.yml` هنوز دیتابیس **JSON** را
تست می‌کند که دیگر در پروژه وجود ندارد؛ بنابراین **همیشه شکست می‌خورد**.

نسخهٔ به‌روزشده که با MySQL کار می‌کند در فایل `docs/backend-health.yml.new`
قرار دارد. چون توکن این جلسه اجازهٔ تغییر فایل‌های `.github/workflows/` را
ندارد، باید این جایگزینی را خودتان انجام دهید.

## روش ۱ — از داخل سایت GitHub (ساده‌ترین)

1. وارد مخزن در GitHub شوید.
2. فایل `docs/backend-health.yml.new` را باز کنید و **همهٔ محتوای آن را کپی** کنید.
3. به مسیر `.github/workflows/backend-health.yml` بروید.
4. روی آیکون مداد (✏️) بزنید، محتوای قبلی را پاک و محتوای کپی‌شده را جای‌گذاری کنید.
5. **Commit changes** را بزنید.

## روش ۲ — از روی سیستم خودتان

```bash
git pull
cp docs/backend-health.yml.new .github/workflows/backend-health.yml
rm docs/backend-health.yml.new docs/CI-WORKFLOW-UPDATE.md
git add -A
git commit -m "به‌روزرسانی ورک‌فلو CI برای MySQL"
git push
```

## اگر اصلاً به تست خودکار نیاز ندارید

می‌توانید ورک‌فلو را کاملاً حذف کنید:

```bash
git rm .github/workflows/backend-health.yml
git commit -m "حذف ورک‌فلو قدیمی"
git push
```

## این ورک‌فلو چه چیزهایی را تست می‌کند؟

- یک دیتابیس واقعی MySQL 8 بالا می‌آورد
- بررسی می‌کند هیچ ارجاعی به AxioDB باقی نمانده باشد
- صحت نحوی همهٔ فایل‌های جاوااسکریپت
- اتصال به دیتابیس و ساخت جدول‌ها
- ورود ۲۵ محصول به‌صورت خودکار
- ثبت‌نام کاربر و اطمینان از ذخیره شدن واقعی در جدول `users`
- سلامت ۱۳ مسیر اصلی API
- ورود مدیر و مسدود بودن مسیرهای مدیریتی بدون توکن
- **ری‌استارت سرور و اطمینان از باقی ماندن داده‌ها**
