### **⚙️ مرحله ۲: تنظیم دیتابیس MySQL**

#### **گزینه A: اگر از XAMPP/WAMP استفاده می‌کنید**
1. **XAMPP/WAMP را اجرا کنید** و مطمئن شوید که **MySQL** در حال اجرا است
2. **phpMyAdmin را باز کنید** (معمولاً در `http://localhost/phpmyadmin`)
3. **یک دیتابیس جدید بسازید:**
   - نام دیتابیس: `arzankala`
   - Collation: `utf8mb4_unicode_ci`

#### **گزینه B: اگر MySQL را به صورت مستقیم نصب کرده‌اید**
1. **MySQL را اجرا کنید**
2. **دیتابیس را بسازید:**
   ```bash
   mysql -u root -p
   ```
   سپس در محیط MySQL:
   ```sql
   CREATE DATABASE arzankala CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   EXIT;
   ```

### **🛠️ مرحله ۳: تنظیم و اجرا پروژه**

1. **وارد پوشه `backend` شوید:**
   ```bash
   cd backend
   ```

2. **وابستگی‌ها را نصب کنید:**
   ```bash
   npm install
   ```
   > **⏳ زمان تخمینی:** ۱-۲ دقیقه (بسته به سرعت اینترنت)

3. **فایل `.env` را برای اتصال به MySQL ایجاد کنید:**
   ```bash
   cp .env.example .env
   ```

4. **فایل `.env` را ویرایش کنید:**
   - در ویندوز: با **Notepad++** یا **VS Code**
   - در لینوکس/مک: با `nano .env` یا `vim .env`

   **محتویات فایل `.env` (برای لوکال):**
   ```env
   # پورت سرور
   PORT=3000

   # اتصال به MySQL لوکال
   MYSQLHOST=localhost
   MYSQLPORT=3306
   MYSQLUSER=root
   MYSQLPASSWORD=رمز_شما_در_MySQL  # اگر رمز ندارید، خالی بگذارید
   MYSQLDATABASE=arzankala

   # امنیت
   JWT_SECRET=یک_رشته_تصادفی_طولانی_مثلاً_abc123xyz456
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=admin123

   # اختیاری
   AUTO_SEED=true
   ```

   > **💡 راهنمای پیدا کردن رمز MySQL:**
   > - اگر از **XAMPP** استفاده می‌کنید، معمولاً **رمز خالی** است
   > - اگر از **WAMP** استفاده می‌کنید، معمولاً **رمز خالی** است
   > - اگر خودتان MySQL را نصب کرده‌اید، رمزی را که هنگام نصب وارد کردید استفاده کنید

5. **دیتابیس را با داده‌های اولیه پر کنید:**
   ```bash
   node seed.js
   ```
   > **✅ خروجی مورد انتظار:**
   > ```
   > ✅ اتصال به MySQL برقرار شد
   > ✅ ساختار جدول‌های MySQL بررسی/ایجاد شد
   > ✅ داده‌گذاری اولیه کامل شد
   > ```

6. **سرور را اجرا کنید:**
   ```bash
   node server.js
   ```
   > **✅ خروجی مورد انتظار:**
   > ```
   > 🚀 سرور ارزان‌کالا روشن شد
   > 📡 پورت: 3000
   > 🗄️ دیتابیس: MySQL @ localhost/arzankala
   > ```

7. **در مرورگر آدرس زیر را باز کنید:**
   [http://localhost:3000](http://localhost:3000)

## ❌ **رفع مشکلات رایج**

| **مشکل** | **راه‌حل** |
|----------|------------|
| **خطای اتصال به MySQL** | مطمئن شوید MySQL در حال اجرا است و اطلاعات `.env` درست هستند |
| **خطای `Access denied for user`** | رمز MySQL را در `.env` چک کنید (اگر از XAMPP استفاده می‌کنید، معمولاً رمز خالی است) |
| **خطای `ECONNREFUSED`** | پورت MySQL را چک کنید (پیش‌فرض 3306) |
| **دیتابیس خالی است** | دستور `node seed.js` را دوباره اجرا کنید |
| **صفحه سفید نمایش داده می‌شود** | از آدرس `http://localhost:3000` استفاده کنید (نه باز کردن مستقیم فایل HTML) |
| **فرم‌ها کار نمی‌کنند** | مطمئن شوید که سرور در حال اجرا است (`node server.js`) |
