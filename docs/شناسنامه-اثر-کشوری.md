## 🎯 هدف پروژه

هدف پروژه **طراحی و پیاده‌سازی یک فروشگاه اینترنتی کامل و حرفه‌ای** برای فروش محصولات دیجیتال شامل:
- موبایل، لپ‌تاپ، تبلت
- لوازم جانبی (هدفون، موس، کیبورد)
- گیمینگ (کنسول، موس گیمینگ، کیبورد مکانیکی)
- دوربین، مانیتور، لوازم خانگی، تلویزیون

این پروژه با **معماری Full-Stack** و ویژگی‌های پیشرفته مانند:
- پیشنهاد هوشمند محصولات
- مقایسه محصولات با هایلایت خودکار تفاوت‌ها
- پنل مدیریت تحلیلی
- تحلیل هوش مصنوعی نظرات
- امنیت بالا
- PWA (قابلیت نصب روی موبایل و دسکتاپ)

به کاربران کمک می‌کند تا **تصمیم‌گیری بهتری در خرید** داشته باشند.

---

## 🏗️ معماری پروژه

### **فرانت‌اند (Frontend)**
- **زبان‌ها:** HTML5, CSS3, JavaScript (ES6+)
- **فریمورک‌ها:** Bootstrap 5 (RTL), Font Awesome 6
- **ویژگی‌ها:**
  - طراحی تیره (Dark Mode) با رنگ اصلی سبز (#00c853)
  - واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ
  - فونت فارسی (Vazir)
  - PWA با Service Worker و Manifest.json

### **بک‌اند (Backend)**
- **زبان:** Node.js (نسخه ۱۸+)
- **فریمورک:** Express.js
- **دیتابیس:** **MySQL** (میزبانی شده روی Railway یا قابل اجرا به صورت لوکال)
- **امنیت:**
  - احراز هویت با JWT
  - رمزنگاری رمز عبور با bcryptjs
  - هدرهای امنیتی با Helmet
  - محدودیت نرخ درخواست

### **معماری نرم‌افزار**
- **Client-Server** با ساختار معنایی HTML
- لایه کلاینت: صفحات استاتیک با JavaScript
- لایه سرور: APIهای RESTful با Node.js/Express
- ذخیره‌سازی: MySQL برای داده‌های دائمی، LocalStorage برای سبد خرید و لیست مقایسه

## 🗄️ دیتابیس

- **نوع دیتابیس:** **MySQL** (میزبانی شده روی **Railway** یا قابل اجرا به صورت لوکال)
- **ساختار:**
  - جدول `products` (۴۵ محصول در ۹ دسته)

  - داده‌های دائمی در MySQL
  - سبد خرید، لیست مقایسه و علاقه‌مندی‌ها در LocalStorage

## 🚀 نحوه اجرا (برای داوران)

### **⚡ روش آنلاین (بدون نیاز به نصب)**
- **آدرس سایت:** [https://arzankala-9.onrender.com/](https://arzankala-9.onrender.com/)
- **نام کاربری مدیر:** `admin`
- **رمز عبور مدیر:** `admin123`

### **💻 روش لوکال (برای اجرا روی سیستم خودتان)**

#### **پیشنیازها:**
- Node.js نسخه **۱۸ یا بالاتر**
- MySQL (می‌توانید از XAMPP/WAMP/MAMP استفاده کنید)

#### **مراحل اجرا:**
1. **کد پروژه را دانلود کنید** (یا از GitHub clone کنید)
2. **وارد پوشه `backend` شوید:**
   ```bash
   cd backend
   ```
3. **وابستگی‌ها را نصب کنید:**
   ```bash
   npm install
   ```
4. **فایل `.env` را برای اتصال به MySQL لوکال ایجاد کنید:**
   ```bash
   cp .env.example .env
   ```
   سپس فایل `.env` را ویرایش کرده و تنظیمات اتصال به MySQL لوکال را وارد کنید:
   ```env
   MYSQLHOST=localhost
   MYSQLPORT=3306
   MYSQLUSER=root
   MYSQLPASSWORD=رمز_شما
   MYSQLDATABASE=arzankala
   JWT_SECRET=یک_رشته_تصادفی_طولانی
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=admin123
   ```
5. **دیتابیس را با داده‌های اولیه پر کنید:**
   ```bash
   node seed.js
   ```
   (دیتابیس با **۴۵ محصول** و کاربر ادمین `admin/admin123` پر می‌شود)
6. **سرور را اجرا کنید:**
   ```bash
   node server.js
   ```
7. **در مرورگر آدرس زیر را باز کنید:**
   [http://localhost:3000](http://localhost:3000)

#### **نکات مهم برای اجرا لوکال:**
- حتماً از آدرس `http://localhost:3000` استفاده کنید (نه باز کردن مستقیم فایل HTML)
- برای پنل مدیریت، با نام کاربری `admin` و رمز عبور `admin123` وارد شوید
- اگر با خطای اتصال به MySQL مواجه شدید، مطمئن شوید که:
  - MySQL در حال اجرا است
  - اطلاعات اتصال در فایل `.env` درست هستند

## 🎨 نوآوری‌ها

1. **الگوریتم پیشنهاد هوشمند** بر اساس **نوع کاربر، بودجه و فوریت خرید**
2. **مقایسه هوشمند محصولات** با **هایلایت خودکار تفاوت‌ها** (سبز برای مشترک، قرمز برای متفاوت)

6. **PWA** برای نصب روی موبایل و دسکتاپ
7. **فیلترهای ترکیبی** برای جستجوی پیشرفته محصولات
8. **طراحی تیره مدرن** با رنگ‌بندی سبز-مشکی و افکت‌های شیشه‌ای
