## بخش ۳ — کارهایی که باید خودتان انجام دهید

### 🔴 بحرانی — قبل از معرفی سایت به کاربران

- [ ] **۱. رمز مدیر را عوض کنید**
  اگر `ADMIN_PASSWORD` را در رندر نگذاشته‌اید، رمز فعلی `admin123` است.
  در Render → Environment → مقدار `ADMIN_PASSWORD` را ست کنید و Redeploy بزنید.

- [ ] **۲. مطمئن شوید `JWT_SECRET` مقدار دارد**
  اگر خالی باشد، کد از یک مقدار پیش‌فرض عمومی استفاده می‌کند و
  هر کسی می‌تواند توکن ادمین جعل کند.
  بررسی: Render → Environment → `JWT_SECRET` باید یک رشته تصادفی طولانی باشد.

- [ ] **۳. ورک‌فلو CI را به‌روز کنید**
  فایل فعلی هنوز دیتابیس JSON را تست می‌کند و همیشه قرمز می‌شود.
  راهنما: `docs/CI-WORKFLOW-UPDATE.md`

### 🟡 مهم

- [ ] **۴. پنل ادمین را در مرورگر باز کنید و چشمی چک کنید**
  چون این بخش رابط گرافیکی است، تست خودکار جای بازدید واقعی را نمی‌گیرد:
  - ورود با کاربر مدیر → صفحه `admin.html`
  - تب داشبورد: چهار نمودار (دسته‌بندی، قیمت، پربازدید، موجودی) رسم شوند
  - تب محصولات: ستون قیمت باید عدد تومانی نشان دهد نه `---`
  - روی «ویرایش» یک محصول بزنید → قیمت باید در کادر پر باشد → تغییر و ذخیره
  - تب نظرات → روی «پاسخ» بزنید → متن وارد کنید → باید ثبت شود
  - تب کاربران → غیرفعال/فعال کردن یک کاربر تستی

- [ ] **۵. تست خرید واقعی از دید کاربر**
  ثبت‌نام → افزودن به سبد → تسویه → مشاهده سفارش در پروفایل
  و سپس دیدن همان سفارش در تب سفارشات پنل ادمین.

- [ ] **۶. تعداد محصولات**
  شما گفتید ۴۵ محصول در دیتابیس دارید، ولی `products.json` فقط ۲۵ مورد دارد.
  یعنی ۲۰ محصول را دستی اضافه کرده‌اید. اگر می‌خواهید این‌ها در استقرار
  بعدی هم بمانند، حتماً از دیتابیس **بکاپ** بگیرید (مورد ۷).

### 🟢 توصیه‌شده

- [ ] **۷. بکاپ‌گیری از دیتابیس**
  Railway در پلن رایگان بکاپ خودکار ندارد. ماهی یک‌بار:
  ```bash
  mysqldump -h HOST -P PORT -u root -p railway > backup-$(date +%F).sql
  ```

- [ ] **۸. محدود کردن دامنه‌ها**
  الان API از هر دامنه‌ای قابل صدا زدن است. اگر می‌خواهید محدود کنید:
  `ALLOWED_ORIGINS=https://USERNAME.github.io,https://YOUR-APP.onrender.com`

- [ ] **۹. حواستان به محدودیت‌های پلن رایگان باشد**
  - Render: سرویس بعد از ۱۵ دقیقه بی‌کاری می‌خوابد؛ اولین درخواست ~۵۰ ثانیه
  - Railway: حدود ۵ دلار اعتبار رایگان در ماه؛ بعد از اتمام دیتابیس متوقف می‌شود

## بخش ۴ — مواردی که عمداً پیاده‌سازی نشده‌اند

اگر سایت قرار است واقعاً فروش داشته باشد، این‌ها لازم می‌شوند:

| مورد | توضیح |
|------|-------|
| درگاه پرداخت واقعی | صفحه `buy.html` شبیه‌سازی است و پولی جابه‌جا نمی‌کند |
| تأیید ایمیل/موبایل | کاربر با هر ایمیلی می‌تواند ثبت‌نام کند |
| فراموشی رمز عبور | مسیر بازیابی رمز وجود ندارد |
| آپلود تصویر محصول | فقط نام فایل ذخیره می‌شود؛ باید عکس را دستی در `frontend/img/` بگذارید |
| کاهش خودکار موجودی هنگام سفارش | الان جدا صدا زده می‌شود؛ بهتر است داخل تراکنش سفارش باشد |
| لاگ و مانیتورینگ | برای ردیابی خطاها در production |
